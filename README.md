# Jon Taylor — Data Analytics Portfolio Homepage

A responsive static homepage built with HTML and CSS for GitHub Pages.

## Files
- `index.html` — page structure and homepage content
- `styles.css` — responsive styling and visual design

## Preview locally
Open `index.html` in a web browser. No build tools are required. An internet connection is used for the Google Fonts import; the page otherwise works as a static site.

## Publish with GitHub Pages
1. Create a public repository named `data-analytics-portfolio` under `jontaylor224`.
2. Upload `index.html`, `styles.css`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub Pages finishes deploying, the site should be available at `https://jontaylor224.github.io/data-analytics-portfolio/`.
